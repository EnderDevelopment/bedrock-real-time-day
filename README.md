# Minecraft Bedrock Real-Time Day Cycle Add-on

Reloj Bedrock 24H is a Minecraft Bedrock behavior pack that syncs the Overworld’s day-and-night cycle to the device’s local clock, making one full Minecraft day last 24 real-world hours.

## Install

1. Run `python package_mcpack.py` in the project directory to generate `Real-Time-24-Hour-Day.mcpack`.
2. Open the generated `.mcpack` file with Minecraft Bedrock to import it.
3. Create or edit a world, open **Behavior Packs**, and activate **Real-Time 24 Hour Day**.
4. Enter the world. The pack sets the Overworld time from the device’s local clock.

## Use

Keep the world open while you want the cycle to run. The add-on updates the Overworld time about once per second. Sunrise aligns with 06:00 local time, noon with 12:00, sunset with 18:00, and midnight with 00:00. Changing the device clock affects the in-game time at the next update. The Nether and the End are not affected.
